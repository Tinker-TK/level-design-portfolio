# 塞尔达传说旷野之息关卡设计分析报告

开放世界中的探索引导 教学组织 系统交互与节奏设计

## 阅读摘要

《旷野之息》的开放世界体验，建立在一个持续运转的过程上：**玩家看到线索，形成自己的目标，利用已有能力到达目标，在解决问题后获得资源或知识，再发现下一个值得前往的地方。** 地形、奖励、能力和叙事共同支撑这个过程。地图的大小只是容器，玩家不断产生新打算，才是探索持续发生的原因。

这份游玩记录呈现出三次显著的学习转变。初始台地让玩家从等待操作提示，转向识别环境中的机会；离开台地后，玩家开始结合视野、感应器和等高线判断路线；进入中后期后，玩家会用制冰避战、用时停改变解题顺序，甚至主动离开暂时不想处理的区域。这说明成长不仅发生在血量、装备和伤害上，也发生在玩家理解世界的方式上。

最值得迁移到其他项目的经验有六项：

1. **先提供可理解、可组合的基础能力，再逐步增加情境复杂度。** 能力数量有限，也能支撑大量不同问题。
2. **把远处目标、路上的新发现和脚边的微小异常连接起来。** 每一次接近目标，都可能改变下一步计划。
3. **教学结束于玩家主动复用知识。** 通关教学房间，只证明完成了当下任务。
4. **允许战斗、地形、物品和环境规则互相提供解法。** 玩家因此能用准备和观察补偿操作不足。
5. **用局部约束组织节奏，同时保留全局退出和改道的空间。** 开放地图同样可以拥有清晰的章节体验。
6. **把挫败拆成理解、执行和重试三种成本。** 有效挑战应让玩家知道下一次可以改变什么。

## 1 分析范围与证据口径

### 1.1 覆盖的游玩阶段

分析覆盖复苏神庙、初始台地、双子山至卡卡利科村和哈特诺村、卓拉区域、格鲁德与依盖队、克洛格森林、利特区域、死亡之山，以及记录后段的一击必杀试炼。主线顺序描述的是这一次游玩的路径，不代表游戏要求所有玩家按此顺序推进。

初始台地的记录最细，适合分析教学顺序和遭遇递进；卓拉路线记录了较完整的战斗与对话节点，适合分析区域节奏；部分神兽内部记录较少，相关补充另作标识。本报告包含这些阶段的机制与剧情信息。

### 1.2 如何理解报告中的结论

**实录观察**指记录中明确发生的行为和感受，例如用木枪点火、根据等高线寻找神庙、在某个机关前感到烦躁。它能证明该体验发生过，不能证明所有玩家都有相同体验。

**资料补充**指开发者公开资料、会议现场报道或攻略中可核对的信息。正文在对应位置给出链接。开发者讲演说明设计方向；攻略只用于核对机制和流程，不用于证明制作组的意图。

**分析判断与迁移建议**是由案例推导的解释和做法。除非明确引用开发者陈述，“这一安排起到了某种作用”不等于“已证实制作组为此而安排”。文中的节奏强弱均为定性分析，没有把记录中的编号当作分钟数，也没有虚构热力图、留存率或死亡统计。

## 2 从流程记录还原整体体验结构

### 2.1 一条由能力成长串联的游玩路径

| 阶段 | 实录中的关键行为 | 玩家正在学会什么 | 关卡承担的主要作用 |
| --- | --- | --- | --- |
| 复苏神庙至台地出口 | 取希卡之石 开宝箱 换装备 走向亮处 | 操作与交互的基本语言 | 降低首次进入世界的理解负担 |
| 台地野外 | 拾取武器 遭遇单体敌人 利用炸药桶 | 物品有用途 环境可参与战斗 | 从按键教学转向情境判断 |
| 台地四神庙 | 磁力 炸弹 时停 制冰及出口练习 | 能力可以处理不同对象关系 | 建立后续探索所需的工具基础 |
| 双子山至两个村落 | 开塔 感应寻庙 驿站交易 扩包 强化 传火 | 观察 导航 补给与长期成长 | 把分散系统接成日常冒险循环 |
| 卓拉与水神兽 | 雨中推进 希多对话 电箭 收集与强敌 | 环境条件会改变行动收益 | 在开放地图中形成区域章节 |
| 格鲁德与雷神兽 | 潜入 香蕉诱敌 磁力暗门 电力谜题 | 注意力操控与跨情境复用 | 将旧能力置入新的规则组合 |
| 森林 利特与死亡之山 | 追踪 迷雾 风向 耐火准备 神兽变形 | 读懂区域差异与空间状态 | 用环境和空间结构组织变化 |
| DLC 初段 | 一击规则下重新规划台地战斗 | 精确控制暴露与失败风险 | 在熟悉空间中重写决策优先级 |

这条路径并不是连续增加系统的直线。记录多次回到旧能力：磁力既出现在教学神庙，也出现在克洛格拼图、依盖暗门和电路谜题；制冰既造路，也用于抬升、改变球的运动与避开敌人。新区域主要改变能力的使用条件，因此过去学到的知识不会迅速失效。

### 2.2 三个尺度的关卡相互嵌套

**世界尺度**回答“接下来去哪”：高塔、聚落、神兽和山体建立方向感。**区域尺度**回答“怎样过去”：河谷、雪山、荆棘、怪物营地和补给点影响路线选择。**局部尺度**回答“眼前怎么解决”：机关、敌人行为和物体关系要求一次具体判断。

优秀的连接发生在不同尺度之间。玩家为了世界尺度的开塔目标进入区域，在途中遇到局部宝箱问题；解决宝箱时发现新的高度或路线，又重新判断世界尺度目标。这也是记录中“本来去做主线，后来去看别的东西”反复发生的结构原因。

> 探索循环：看见线索 → 产生目标 → 选择路线与准备 → 处理局部问题 → 获得资源或知识 → 更新目标。

这条循环不要求每次都战斗，也不要求每次都有贵重奖励。登高后看清地形、发现一条安全路、确认某种材料能导电，同样会改变下一步决策。

## 3 初始台地如何把玩家教到能够自由探索

### 3.1 从封闭空间逐步扩大注意范围

苏醒时可见度较低，石台通过镜头、亮光和靠近后的反馈成为明确目标。第二个空间只增加宝箱、背包、装备和开门。玩家尚不熟悉操作时，场景提供较少的竞争信息，每一步行动与结果距离都很近。

走出复苏神庙后，画面从受限空间变为开阔远景。这里同时发生两件事：情绪从未知转向舒展，注意范围从身边交互扩大到远处世界。附近的老人、火堆、闪光物品和可拾取资源又把玩家拉回可以立即执行的小动作，避免远景展示之后出现行动真空。

**可迁移做法**：大型场景的首次揭示之前，先让玩家掌握一个最基本的交互；揭示之后，在近处给出一项不用重新理解规则就能完成的行动。这样，宏大感可以转化为进入世界的意愿。

### 3.2 边界和离开方式共同构成教学目标

正常新手流程中，初始台地的地形高差与尚未取得的滑翔伞形成清晰边界。玩家看得见外面的世界，却需要先完成台地目标，才获得常规离开方式。这个目标把四座神庙、能力获取和基础生存经验串在一起。

这是一种有边界的自由练习。玩家能在边界内安排探索，但设计仍能确保正常离开前已经接触关键能力。获得滑翔伞时，奖励又直接改变可达空间，让“完成教学”拥有可以亲手感受到的意义。

迁移时应让门槛与即将开放的玩法相关。例如，后续地图需要玩家读懂高差，那么新手区的完成奖励最好扩展跨越高差的能力，而不只是播放一句“教程结束”。

### 3.3 战斗递进的关键是增加判断维度

记录中的早期战斗大多只有一个敌人，后续逐渐出现盾牌、长枪、远程攻击、蓝色敌人、营地以及炸药桶。这个变化使玩家从判断“何时攻击”，转向判断“先打谁、站在哪里、能否利用场地”。

骷髅头营地尤其适合作为案例：特殊轮廓先让玩家愿意靠近，放哨弓箭手使威胁有层次，爆炸物提供可观察的机会，较强敌人让直接冲进去付出代价。记录中先处理哨兵、再爆炸削弱、最后补刀，说明战斗已经转化为一连串决策。

这次死亡可以被理解为该玩家的一次综合实践，但营地并非所有人的固定“教程毕业考试”。开放路线可能让另一名玩家更早、更晚进入，或直接绕开。

**可迁移做法**：先保持敌人数量和攻击方向容易理解，再逐个引入角色差异与场地工具。评估难度时，除了数量与血量，还要看玩家同时需要留意多少方向、是否有安全观察位，以及能否恢复或撤退。

### 3.4 四种能力形成可持续扩展的解题语言

| 能力 | 神庙中的入门问题 | 记录中的进一步变化 | 野外迁移体现 |
| --- | --- | --- | --- |
| 磁力 | 移开金属板 找到通道 | 搬桥 开门 操纵金属箱战斗 | 水底宝箱 金属拼图 暗门 电路 |
| 遥控炸弹 | 炸开障碍 | 投送位置 时机控制 两类炸弹交替 | 清障 营地战斗 扩展远程处理方式 |
| 静止器 | 停住运动物体 | 积累打击效果 冻结机关时序 | 移开大石 处理传送带和球体 |
| 制冰器 | 在水上建立落脚点 | 抬升物体 改变斜面 在水流表面造冰 | 水面取宝 铺路避战 改变球的路线 |

四种能力的教学并未在“功能介绍”处结束。金属板先是障碍，之后成为桥；冰柱先是踏脚点，之后承担抬升和支撑作用。变化的核心是物体之间的关系，而不只是换一张贴图或增加一次重复操作。

记录还多次出现神庙出口附近的复习：水底宝箱、石头下的奖励、需要造路才能取得的物品。封闭房间里的提示已经撤去，玩家要自己判断该用刚学的能力。**这种主动识别，是教学迁移最直接的证据。**

### 3.5 生存教学将资源与环境需求放在一起

雪山附近的暖暖草果、锅、木屋日记、防寒料理和防寒服，让低温成为一个可以准备的问题。记录中先吃防寒食物，再获得防寒服；玩家因此体验到临时消耗品与持续装备的差别。

先出现需求，再认识对应资源，会让资源具有上下文。玩家记住的不只是物品名称，还包括“遇到什么情况时，我该去哪里找它”。但边界处必须给予足够反馈和回撤机会，否则环境教学容易变成看不懂原因的持续扣血。

## 4 地形与兴趣点如何引导自主探索

### 4.1 看得见和想过去是两项不同工作

记录中的兴趣点来源非常丰富：骷髅头营地靠轮廓吸引；高塔靠高度和功能吸引；流星靠动态事件吸引；孤立平台、风车和不自然的排列靠局部异常吸引。由此可见，兴趣点并不必须拥有宏大建筑，只需要在当前环境中形成值得解释的差异。

可以把一次有效吸引拆成三个条件：**被注意到、被认为有意义、被判断为可以接近。** 只做巨大地标，可能获得视线，却没有行动；只放高价值物品，可能因为遮挡而从未被发现；看见奖励却不知道任何接近办法，则容易形成挫败。

### 4.2 远中近景承担不同任务

| 观察尺度 | 记录中的线索 | 玩家问题 | 设计用途 |
| --- | --- | --- | --- |
| 远景 | 高塔 山顶 神兽 聚落 | 往哪个方向走 | 建立较长时间的行动目标 |
| 中景 | 营地 岩壁栈道 峡谷缺口 | 是否值得改道 | 在途中制造新选择 |
| 近景 | 风车 方块 缺口 水中宝箱 | 这里有什么异常 | 发起一次观察或操作挑战 |

三个尺度需要彼此衔接。玩家爬上塔后，应能看见新的候选目标；靠近一个候选目标时，应有中近景细节逐步出现。若所有内容从很远处就完整暴露，行走容易只剩下缩短距离；若长期什么都看不到，玩家则难以保持方向感。

### 4.3 遮挡使行走不断产生新信息

“峡谷只显示一半”是记录中的关键观察。玩家知道那里有东西，但还不知道全部；移动到新的角度，就能获得额外信息。于是绕行、爬升和转动镜头本身都有了目的。

CEDEC 2017 的现场报道介绍了开发团队使用地形吸引与三角形结构组织路线：山丘提供攀爬或绕行选择，并让后方目标逐渐进入视野。报道也呈现了团队用试玩轨迹检查引导效果的做法。[《Fami通》会议现场报道](https://www.famitsu.com/news/201708/31140870.html)

结合实录，可将这类方法落实为“遮挡后必须兑现新信息”：放一块山岩，除了改变路线，还应检查绕过它后玩家能看见什么。三角形只是便于组织这种关系的几何手段；一个三角形山体如果不改变视野、选择或到达体验，就没有自动获得好的关卡设计。

### 4.4 高度同时带来信息和移动优势

记录多次主动爬高环顾、开塔后滑翔、在空中被宝箱吸引。高处的回报包括更大的观察范围、对地形的重新理解，以及可利用高度开始移动的机会。开塔因此同时改变地图信息与实际行动条件。

水中高塔周围的休息石块，又把游泳拆成几个短距离判断。塔身上的平台则让攀爬的精力管理具有阶段性。这里不是靠额外插入战斗解决赶路单调，而是让移动本身有计划、执行、休息和调整。

原记录中“跳几次刚好到顶”不能成为通用参数。可迁移的是测试起点精力、连续攀爬长度、休息点可见性以及一次误判后的损失。

### 4.5 感应器给出不完整信息 从而保留推理

感应器响但视野中没有神庙，玩家查看等高线，推测目标位于上方。这时声音、地形和地图相互补充，玩家要作出空间判断。若提示直接标出精确入口，这一推理过程便会缩短。

不完整信息有效的前提，是玩家能通过行动进一步缩小范围。若向任何方向移动都听见同样的反馈，或地图难以区分上下层，线索就可能变成噪声。测试时应检查玩家能否说出一个合理的下一步，而不只是确认提示已经播放。

## 5 神庙如何组织学习与可选难度

### 5.1 同一规则的变化比单纯增加步骤更重要

记录中的炸弹弹射装置先展示球的运动，再让玩家利用弹射，最终要求把炸弹送到合适位置；制冰从垫脚、抬门发展到改变球路；后期双炸弹关卡则引入交替使用与引爆顺序。这些变化逐步把注意力从按钮本身转移到位置、时机和状态关系。

一个可复用的教学结构是：**清楚地展示规则 → 让玩家低风险验证 → 改变一个条件 → 要求重新组合。** 这不是对所有神庙的统一结构判定，而是从多条记录中提炼出的设计模式。

设计时应优先问“这一题新增了哪一个判断”。如果只是把同一种操作做三次，长度增加了，理解未必加深；如果同时改变方向、速度、材料和失败规则，玩家又很难确定究竟哪里出了错。

### 5.2 可选宝箱为同一空间提供第二层问题

宝箱常位于更高处、更偏的角度，或需要额外操作的位置。主通路让玩家理解核心规则，可选奖励则吸引愿意继续研究的人尝试组合用法。记录中跷跷板宝箱、横向制冰取宝，以及神兽尾部暂时拿不到的宝箱，都可以从这个角度理解。

这种组织方式有助于兼容不同熟练度，但必须让“可选”能被判断出来。若宝箱位置与主线目标没有区分，玩家可能误以为不拿就无法推进；若解题成本远高于奖励价值，原本的额外挑战又会变成不划算的耗时。

### 5.3 多解来自可组合规则与结果判定

记录中“动与静的选择”的解法改变了处理顺序：先搬运石球，再用时停把球打到对面，最后借石头和时机通过激光。这个案例说明，玩家不必只沿着最直观的动作顺序前进，可以重新安排资源和机关状态。

对项目设计的启示是：适合开放解法的问题，应围绕可识别的结果判定，例如物体到达、重量满足、路径打通；同时允许多种操作达到该状态。若每一步都必须按隐藏脚本依次执行，就很容易拒绝逻辑成立的解法。

原记录询问磁力神庙的小型守护者是否有其他解法。该战斗也可使用常规武器处理；金属箱是在当地突出展示的一种工具。[磁力试炼攻略](https://www.thonky.com/zelda-breath-of-the-wild/magnesis-trial) 报告更关注由此可验证的设计问题：是否必须使用当前教学能力，还是只需展示它有用，并允许玩家自行选择。

### 5.4 神庙奖励可以放在挑战的终点而非挑战的开端

克洛格森林的跟踪试炼、装备限制试炼等，在进入神庙之前就已经构成主要挑战。记录中“进去直接过”不应简单归为神庙内容不足，因为需要计算的完整单位是“寻找或完成前置挑战，再进入神庙领取回报”。

这能避免连续两次高负担挑战，也让野外探索承担谜题功能。迁移时应跨越场景边界计算体验成本；单独统计室内房间数量，容易误判实际内容量。

## 6 系统交互如何让有限内容产生多种玩法

### 6.1 从识别物品名字转向理解物品属性

“木制长枪也能点燃，然后给锅点火”是整份记录中最有代表性的惊喜。玩家把武器属性与火的作用联系起来，发现一个物品能参与另一套活动。之后金属箱既能搬运又能导电，进一步强化了按属性理解世界的方式。

CEDEC 官方评选说明明确将材质与物理在游戏设计和关卡设计中的结合列为本作特点。这支持了系统交互的重要性，但不能用来证明任何一个具体宝箱或怪物的安排意图。[CEDEC 官方游戏设计评选说明](https://cedec.cesa.or.jp/2017/event/awards_GD.html)

从这些实录可推导出一个实用原则：当玩家认识了某种属性，后续场景应多次允许其作出相近预测。每一次预测成功，都能增加玩家尝试新组合的信心。

### 6.2 物体关系让解法跨越活动类型

| 已有知识 | 原本的应用 | 记录中的迁移 | 设计意义 |
| --- | --- | --- | --- |
| 木制物体可以燃烧 | 火把与点火 | 木枪点燃烹饪火源 | 武器也能参与生存 |
| 金属物体可被磁力操作 | 神庙搬运 | 依盖队暗门 克洛格拼图 | 教学能力进入探索与潜入 |
| 重物和爆炸可产生伤害 | 场景演示 | 营地先爆炸再补刀 | 观察能降低战斗压力 |
| 冰柱提供支撑 | 造路取宝 | 绕开高塔附近敌人 | 解谜能力变成路线能力 |
| 时停能改变运动时机 | 停机关 | 传送带 激光与球组合 | 局部规则支持自选解题顺序 |

同一条规则进入多个活动类型，可以减少“只在某一间房里有用”的孤立机制。不过，组合并不自动意味着平衡：如果一个低成本方法对所有敌人和地形都最好，其他系统仍会被放弃。

### 6.3 武器消耗与奖励形成循环 也产生心理成本

早期战斗会损耗树枝，敌人又掉落新的棒、弓或盾。对这条游玩路径而言，消耗与补充让玩家接触新武器，营地也因此具有补给价值。但“沿途有补充”不能保证任何打法下都不会缺武器。

这个循环至少需要平衡三件事：玩家能否预判消耗，能否获得可接受的替代品，战利品是否值得承担本次风险。如果武器太珍贵、奖励太不确定，玩家可能更愿意躲开战斗；如果补给完全没有压力，尝试不同战术的动机又会减弱。

设计复盘不能只写“耐久鼓励换武器”。应进一步观察玩家是在主动实验，还是因怕损失而长期囤积。两种行为都可能由同一系统产生。

### 6.4 克洛格果实和强化系统改变旧内容的价值

初次遇到克洛格谜题时，异常本身就可以吸引玩家。伯库林任务解释扩包后，同一种发现又获得实际用途。大精灵的强化服务则让卖出物品、获得卢比和收集材料与长期成长产生关系。

这是对已有内容的重新解释：玩家不必立刻看到更多种类的物体，也可能因为刚理解其用途，而重新注意沿途的旧物体。要发挥这种效果，早期接触应足够轻，功能揭示后也应方便再次遇到对应资源。

## 7 卓拉区域与水神兽的节奏分析

### 7.1 开放世界中的一条相对集中的区域路线

卓拉路线在记录中具有明显的连续性：桥梁、八爪怪、蜥蜴战士、滚石、弓箭小队、希多对话和精英敌人不断交替。雨天又使部分常用处理方式失效，例如记录中的爆炸箭无法正常引爆。环境、敌人和对话共同构成了区域辨识度。

这条路线可分析为一种相对集中的推进体验：道路和河谷提供方向，远程威胁要求观察，补给支持继续前进，希多在途中反复出现，提供确认和情绪上的支持。它保留在开放地图中，玩家仍可能改道或利用其他能力跳过局部段落。

**可迁移经验**：全局允许自由选区，区域内部仍可安排一段较集中、节奏较强的旅程。关键是让集中路线具备情境理由，并让绕行的玩家理解自己放弃或获得了什么。

### 7.2 用实录节点重建节奏变化

| 节奏段 | 记录中的事件 | 体验作用分析 |
| --- | --- | --- |
| 进入区域 | 桥边水中敌人与蜥蜴战士 | 建立河流地形和新敌人的基本压力 |
| 首轮推进 | 对话 滚石 小队 补给 | 在遭遇之间确认路线并恢复资源 |
| 压力集中 | 电箭射手与混合队伍 | 迫使玩家处理优先级和掩体位置 |
| 中段确认 | 希多说明还有一段路 | 降低对路程的不确定感 同时也可能放大疲劳 |
| 接近聚落 | 桥上对话与精英交战 | 为到达前安排一个可记忆的节点 |
| 到达领地 | 聚落与神庙 | 从连续威胁切换到观察和准备 |
| 新能力与准备 | 连续上瀑布 人马区域 | 把区域移动能力与后续目标连接 |

节奏不宜画成单一“越来越难”的曲线。战斗强度、资源消耗和认知负担是不同维度：一场简单但无法绕开的远程遭遇，可能让已疲劳的玩家更厌烦；一段难解谜题虽然没有生命危险，也可能具有很高心理压力。

记录中的“还有一半路程”值得单独测试。对仍有余力的人，它是继续前进的承诺；对已经耗尽耐心的人，它可能传达“还没结束”。同一句提示的作用取决于前段耗时、剩余补给和玩家当时状态。

### 7.3 人马是挑战机会 收集目标不应被误读成击杀目标

实录在此出现需要多次尝试的人马战，玩家由此感到战斗深度。机制上，这一阶段的任务要求收集电箭，周围树干等位置可拾取，玩家可以避开人马；接近水神兽时则结合破冰、攀瀑与空中射击。这些是对原记录的流程补充。[Zelda Dungeon 卓拉区域攻略](https://www.zeldadungeon.net/breath-of-the-wild-walkthrough/zoras-domain/)

设计上的价值在于：同一目标允许不同风险策略。愿意战斗的人获得强敌实践，尚未准备好的玩家也能通过观察和潜行推进。若任务表达让大量新手误以为必须击杀，就会把开放解法压缩成一个不必要的难度门槛。

因此，复用这类布局时，应让真正的任务对象可被明确识别。强敌的存在可以制造压力，但目标描述、可拾取物和安全观察位置必须共同告诉玩家还有别的选择。

### 7.4 神兽内部将空间本身变成可操作对象

资料补充：水神兽地图允许调节象鼻，改变喷水位置，并参与水轮与灭火等问题；神兽内需要激活多个终端。与在固定房间里搬动物体相比，这里多了一项会影响空间关系的全局控制。[Zelda Dungeon 水神兽机制说明](https://zeldadungeon.net/wiki/Divine_Beast_Vah_Ruta)

由此可分析出一种关卡升级方式：玩家先认识局部机关，再理解更大范围的控制如何改变它。设计应帮助玩家形成“我刚才做的改变导致那里发生变化”的因果联系。若控制操作与结果相距很远、变化不可见，就容易退化成反复切菜单试错。

这一结构与记录中雷神兽的旋转、风神兽的倾斜和火神兽的翻转可以对照：能力成长的一部分，是逐渐把整个空间纳入自己的操作范围。

### 7.5 战斗高潮后的奖励影响下一段冒险

资料补充：水咒盖侬后阶段提高水位，使战场落脚范围收窄，并出现可用制冰器处理的冰块；完成神兽后获得米法的祈福。[Zelda Universe 水神兽攻略](https://zeldauniverse.net/guides/breath-of-the-wild/walkthrough/chapter-9-divine-beast-vah-ruta/)

从设计角度看，战场变化可以要求玩家重新安排移动与出手机会，避免后半段只重复前半段。恢复类奖励则可能降低后续探索中对死亡的顾虑，让区域完成的意义延伸到离开之后。这里描述的是机制可能产生的效果，原记录没有足够细节判定玩家在每个首领阶段的具体感受。

水神兽整段最值得借鉴的是跨环节连接：进城路让玩家认识区域条件，聚落提供准备空间，后续任务重新使用区域能力，完成奖励再改变下一轮探索。一个区域由这些关系获得完整感。

## 8 其他区域如何在通用规则上形成差异

### 8.1 格鲁德与依盖队改变玩家对敌人注意力的处理

依盖队据点先通过火把、旗帜和可燃入口让玩家观察环境。香蕉提示之后，敌人从单个巡逻到守门，再到多名敌人交错活动。玩家需要关心敌人看向哪里、何时离开，以及自己何时可以通过。

三个地下宝箱又提供了一个有价值的引导关系：玩家因宝箱启用磁力，随后有机会注意到磁力可作用的暗门。这里的提示没有脱离玩家当前目的，而是借取宝这个行为把视线带到下一步问题。

可盖战的记录表现为时机判断到磁力利用的变化，可以看作对注意、出手时机与旧能力复用的收束。迁移时要警惕失败成本：潜入若一失误就要求重做很长一段，玩家学到的可能是避免实验，而非理解巡逻规则。

### 8.2 神兽差异来自空间操作方式

| 神兽 | 记录或补充所体现的控制 | 主要空间判断 | 迁移时的风险 |
| --- | --- | --- | --- |
| 水神兽 | 调节象鼻与水流 | 水流如何影响机关与通路 | 控制与结果分离导致因果不清 |
| 雷神兽 | 旋转内部结构与电路 | 朝向 连通关系与移动路线 | 同时处理过多状态造成迷失 |
| 风神兽 | 改变倾斜 | 方向变化如何影响运动和到达 | 菜单切换打断空间理解 |
| 火神兽 | 翻转结构及明暗变化 | 当前墙面与地面的关系 | 暗处信息不足叠加方向负担 |

这种变化使用了相近的目标框架，却让玩家在不同空间关系上思考。好处是降低重新认识整个系统的成本，风险是终端、室内风格和结构模式反复出现后，玩家可能更快预判内容。

### 8.3 森林把发现过程做成关卡

跟踪任务中的停步、回头、受惊、误认影子和突发野生动物，让“保持距离”在时间上产生变化。角色台词可以提示行为状态，但如果玩家需要反复重做相同的慢速行走，叙事细节会迅速失去新鲜感。

迷雾和磁力线索则把导航本身作为问题。它们与普通道路的区别不在于距离更长，而在于玩家必须解释环境。记录中对装备限制试炼的手感不满提示：关卡要求玩家精确执行之前，应先保证操作、碰撞和失败条件足够稳定可读。

### 8.4 死亡之山显示环境反制知识的重要性

记录先出现“火焰地形没有反制方法”的挫败，后面又记到在 NPC 处购买耐火药。两条记录不一定指同一种危险，不能把前一次挫败直接归因于没有买药。可以确认的是，死亡之山的环境燃烧有耐火药等应对渠道，而且普通耐热效果不能替代这一防护。[死亡之山环境机制](https://www.zeldadungeon.net/wiki/Death_Mountain_%28Breath_of_the_Wild%29)

这种情况揭示了环境门槛的双重要求：危险要明显，准备路径也要能被发现。尤其当不同环境状态需要不同装备或药品时，应让玩家清楚区分问题类型，避免凭名称相近的物品反复无效尝试。

### 8.5 DLC 通过改变风险重用熟悉空间

在一击规则下，记录中的行为转向规划路线、逐个处理敌人。原先可以承受的一次暴露变成高代价，熟悉的营地因而产生新的问题。基础空间未必需要大幅扩张，只要改变失败规则，就能改变玩家注意的内容。

这一方法适合面向已经理解基础机制的玩家。失败惩罚越高，攻击预兆、视野、碰撞一致性和重试距离就越重要。后段对特定试炼的强烈不满，说明风险提高并不必然提升趣味；它也可能放大之前尚能容忍的执行问题。

## 9 长期探索动力来自奖励 叙事与节奏空隙

### 9.1 奖励应覆盖不同时间尺度

| 奖励类型 | 实录案例 | 对下一步行为的影响 |
| --- | --- | --- |
| 即时可用 | 武器 箭 食材 补给 | 支持继续冒险或尝试新打法 |
| 能力与成长 | 精力 血量 扩包 强化 | 让更多路线与挑战值得尝试 |
| 信息 | 地图 感应器 NPC 提示 | 产生新的目的地或行动假设 |
| 认知 | 金属箱能导电 木枪能点火 | 扩展玩家自行提出解法的范围 |
| 情境与情感 | 村民生活 回忆 同伴对话 | 让地点和行动具有个人意义 |

同一个宝箱在不同阶段会有不同价值。前期的箭可能补充稀缺手段，后期同类数量则可能缺乏吸引力。评估奖励时，应把当前库存、获取成本和替代渠道一起考虑。

### 9.2 驿站和村庄让冒险暂停得有价值

双子驿站集中出现交易、睡觉、马匹与旅途信息；村庄提供扩展装备、主线背景与生活细节。它们允许玩家整理资源和重新计划，并为下一段旅程提供理由。

记录中驿站之后较长一段少有敌人，却有植物、宝箱和观察机会。这种低威胁区间不是天然空洞：它让玩家有余力留意环境。如果每段路都用战斗填满，料理资源和世界细节反而可能失去被注意的机会。

### 9.3 主线信息分段释放降低持续听讲的压力

英帕对话中可暂时中断、之后再继续，是记录中明确被注意到的节奏处理。玩家可以按自己的状态接收背景信息，而不是因为急于恢复操作而跳过一整段内容。

哈特诺研究所的传火任务则将系统解锁与一次实际行程结合，中途火源作为接续点，使重复劳动和失败回退有所缓冲。研究所日记、说明书与普通 NPC 对话进一步提供可选择的信息深度。

### 9.4 世界事件为计划制造可接受的意外

流星让玩家主动改变方向；夜间骷髅和蝙蝠改变短时遭遇；血月通过演出让怪物复活进入世界叙事。记录最后将这些体验概括为“刻意制造的随机性”，可以进一步理解为多种内容和条件在游玩中相遇。

但主观上的偶遇，不能证明某个具体点位由随机算法生成。迁移时，应区分固定地点、时间或天气条件、移动对象与触发事件，分别控制出现频率和可重复性。

意外还需要允许放弃。记录里遇到打不过的敌人就离开，之后传送去另一处，说明改道本身成为正常玩法。玩家有值得去的替代目标时，一次局部受挫不必终止整段游玩。

## 10 从体验不畅提炼改进方向

### 10.1 先区分玩家在哪里失去了控制感

| 实录问题 | 问题性质判断 | 可迁移的改进方向 | 如何验证 |
| --- | --- | --- | --- |
| 奔跑碰墙转攀爬 再按 B 变成松手 | 上下文切换时动作语义突变 | 强化状态反馈 检查输入缓冲与取消规则 | 观察误松手发生前玩家想执行什么 |
| 体感控球与部分精细操作令人烦躁 | 已理解目标但执行不稳定 | 校准与重置更方便 提供替代输入或更宽容容差 | 分别测知道解法前后所花的时间 |
| 风藏在柱子后导致恼火 | 关键线索可能未被注意 | 让气流 动态物或声音提供可追踪证据 | 玩家能否解释发现线索的过程 |
| 恋情支线与集市位置不清 | 任务对象与下一步行动不明确 | 提示逐级缩小范围 保留调查空间 | 玩家能否说出下一步找谁 去哪或等什么 |
| 见到圆形底座但找不到对应物 | 未知是否具备推进条件 | 区分当前谜题与需稍后处理的线索 | 是否形成有根据的猜测 并愿意做标记 |
| 火焰地形似乎无法处理 | 反制渠道尚未被发现 | 在进入危险前暴露求助与准备机会 | 首次受伤后是否知道如何调整 |
| 火咒盖侬吸入炸弹的处理不明 | 机制线索到行动之间连接不足 | 加强吸入效果与可投入物的反馈 | 失败后能否自然提出相关尝试 |
| 一击试炼中强烈挫败 | 高风险放大操作与重试成本 | 明确危险边界 缩短无新增学习的重复段落 | 统计死亡原因和重复时间的占比 |

这些是针对类似项目的设计建议，不能仅凭单条记录确定原关卡一定缺少某种提示。例如，玩家没看到一个线索，可能来自镜头方向、注意竞争或线索出现时机，而不只是线索太暗。

### 10.2 困难应能转化为新的尝试

可以用三个问题检查挑战是否有效：玩家是否知道目标；是否看到了足以提出假设的证据；一次失败是否帮助判断假设或执行哪里有问题。

若知道目标且能提出新办法，卡住仍可能是有价值的思考。若知道办法却反复败在不稳定输入上，主要问题在执行。若失败后既不知道原因，也不知道下次改变什么，则应优先检查信息与反馈。

高惩罚关卡必须尤其重视第三点。失败动画、重新跑路和已掌握步骤的重复，不会自动增加挑战深度，只会增加下一次有效尝试的成本。

## 11 可直接用于项目的关卡设计方法

### 11.1 从一段可玩区域开始验证探索循环

下面是一份假设的原型方案，用于检验方法，不是对海拉鲁真实地图的复刻。

| 原型节点 | 设计内容 | 要验证的核心行为 |
| --- | --- | --- |
| 入口安全处 | 一个醒目的远景目标和少量近处资源 | 玩家能否自行选出目的地 |
| 第一段遮挡 | 山丘提供登高与绕行选择 | 玩家是否注意路线代价和新视野 |
| 野外小问题 | 可见但需要能力处理的奖励 | 玩家是否主动回忆教学规则 |
| 可绕开的营地 | 正面战斗 高处射击 场景物体至少两类可行策略 | 不同玩家是否作出有意义的不同选择 |
| 补给与提示点 | 恢复资源并提供区域信息 | 玩家是否有理由停留和重新准备 |
| 局部试炼 | 单一规则变化加一项可选挑战 | 能否区分基础理解与深入掌握 |
| 出口观察处 | 回看旧路并发现新目标 | 玩家是否在奖励之后继续形成计划 |

先把这个闭环做通，再扩大地图面积。扩大前应确认：玩家绕路能够获得有意义的回报；不走预设路线仍有内容可理解；能力迁移发生在没有显式指令的场景里。

### 11.2 每个兴趣点写清六件事

1. **吸引信号**：玩家从哪些高度、方向和光照条件下能注意到它。
2. **行动理由**：它承诺资源、知识、成长、景观还是情境内容。
3. **接近方式**：主要入口之外，有没有攀爬、滑翔或绕行进入的可能。
4. **核心判断**：玩家在这里真正需要理解或选择什么。
5. **回报与失败**：完成获得什么，失败后保留什么，能否退出。
6. **后续连接**：离开时能发现什么，刚学会的知识在哪里再次有用。

这比只写“此处放营地，此处放宝箱”更接近可测试的关卡方案。空间、美术、系统和奖励都围绕同一项玩家行为工作。

### 11.3 用依赖关系管理非线性教学

关卡文档应区分“玩家必然具备的能力”“可能具备的装备”“可能掌握的知识”。三者不能混为一谈。拥有弓并不代表熟悉空中射击；见过金属箱也不代表理解导电。

对于非线性可达内容，先列出最低前提，再检查前提是否由流程保证。若不能保证，可在当地提供可选提示、低风险演示或替代解法。教学材料放在附近仍不够，还要确认玩家在不同进入方向下能够看见并理解。

### 11.4 用试玩检验假设 而非只统计完成率

| 测试问题 | 可观察证据 | 对结果的解释边界 |
| --- | --- | --- |
| 目标是否吸引人 | 首次注意位置 自发接近与改道理由 | 走向目标也可能只是服从任务标记 |
| 教学是否迁移 | 无提示的新场景中是否主动使用同一规则 | 教学房间通过率不能替代迁移表现 |
| 路线是否支持选择 | 首次路线分布 绕路收益 回撤与重规划 | 路径分散也可能来自迷路 |
| 难度是否合适 | 失败原因 补给消耗 下一次策略变化 | 死亡少不一定有趣 死亡多不一定深刻 |
| 线索是否可读 | 玩家能否描述假设与线索之间的关系 | 看见对象不等于理解作用 |
| 奖励是否有用 | 是否拾取 使用 替换或丢弃 | 开箱率高也可能只是习惯性清空 |
| 重试是否合理 | 有效新尝试与重复跑路分别耗时多少 | 总通关时长不能说明时间花在哪里 |

建议分开观察首次接触者和熟练玩家，并至少覆盖道路进入、侧向攀爬、空中落入等有代表性的情况。这里不设任意的合格百分比；先看原型基线和具体失败原因，再决定需要改善的阈值。

### 11.5 小团队应优先借鉴关系设计

值得优先实现的，是少量稳定规则、清晰的环境反馈、多种进入方式和短距离的教学迁移。它们可以在一小块地图内验证。

需要慎重扩展的，是大量可组合材质、复杂天气与物理交互，以及高成本的全方向内容覆盖。每增加一项规则，都应检查它与既有对象如何相互影响、怎样反馈以及如何测试。规则很多但经常例外，会消耗玩家对世界的信任。

如果项目希望强调作者控制的情节，或没有资源支持广泛交互，可以保留相对明确的线路，只在局部问题、接近方式和奖励顺序上提供自由。方法的适用程度取决于项目想让玩家决定什么。

## 12 设计经验归纳

《旷野之息》在这份记录中最突出的成果，是让玩家逐渐学会自行组织冒险。早期依赖亮光和镜头，之后利用感应器与地形判断位置，最终能重新排列机关操作、借能力绕开战斗，并在当前区域不合适时改选目标。

这条变化由若干具体关系共同支撑：能力与野外问题相连，地标与实际用途相连，路线与观察机会相连，消耗与补给相连，局部章节与全局自由相连。只复制高塔、神庙、宝箱或克洛格的外形，无法保证这些关系随之出现。

因此，对开放世界关卡最有用的评审问题是：**玩家此刻为什么愿意行动，凭什么作出判断，行动之后获得了什么新的可能？** 当这三个问题在连续多个地点都有清楚答案，探索才会持续产生动力。

后续记录可以采用以下格式，保留当时的直觉，同时增强分析所需的证据。

| 字段 | 示例 |
| --- | --- |
| 进入条件 | 从神庙出口到水边 刚学会磁力 |
| 看见或听见什么 | 水底存在可见宝箱 |
| 当时的目标 | 想把宝箱拿上来 |
| 提出的假设 | 既然是金属 也许能用刚学的磁力 |
| 实际操作与反馈 | 启用磁力并尝试移动 记录成功或失败 |
| 情绪与原因 | 因为没有提示也解开而有掌握感 |
| 设计解释 | 候选解释为出口处的能力迁移练习 |

记录“我猜错了什么”和“为什么决定离开”，往往比补齐敌人数量更有价值。它们能够直接暴露目标表达、环境可读性和资源预期之间的差距。
